ROTEIRO DE REUNIAO - TRANSFERENCIA DO PROJETO 5 ESTRELAS

Objetivo deste documento:
Servir como roteiro de apresentacao para transferir o projeto 5 Estrelas para
outra pessoa. A ideia e explicar o que precisa estar configurado, quais pastas
importam, como funciona a extracao Oracle, como rodar a pipeline e onde conferir
os resultados.

Tempo sugerido para apresentacao: 40 minutos.


1. ABERTURA - O QUE E ESTE PROJETO

O projeto 5 Estrelas e uma automacao em Python para tratar a base de avaliacoes
e negativas do processo 5 Estrelas.

Ele faz quatro coisas principais:

1. Extrai ou recebe a base bruta do Oracle.
2. Trata e valida os dados de avaliacoes.
3. Trata e valida os dados de negativas.
4. Gera arquivos finais para Power BI e arquivos separados por classificacao.

O projeto foi organizado para manter as regras em scripts Python e os ajustes de
negocio em planilhas de insumos. Assim, a pessoa que assumir precisa saber onde
ficam as regras, onde ficam as entradas e quais comandos executar.


2. VISAO RAPIDA DO FLUXO

Fluxo completo:

1. Configurar ambiente Python e bibliotecas.
2. Configurar acesso Oracle no arquivo local scripts/.env.oracle.
3. Rodar a extracao Oracle, quando for necessario buscar a base.
4. Colocar o CSV de entrada no caminho esperado pela pipeline.
5. Rodar pre-validacao de avaliacoes.
6. Rodar pre-validacao de negativas, se houver arquivo de negativas.
7. Ajustar insumos/regras conforme as auditorias geradas.
8. Rodar os arquivos finais para Power BI.
9. Rodar a separacao por grupo/classificacao, quando necessario.
10. Conferir os resumos e arquivos finais.

5. CONFIGURACAO DO ARQUIVO .ENV.ORACLE

O arquivo local de configuracao fica em:

scripts/.env.oracle

Existe um modelo em:

scripts/.env.oracle.example

Passo para configurar:

1. Copiar scripts/.env.oracle.example.
2. Criar scripts/.env.oracle.
3. Preencher usuario, senha, DSN, caminho do Oracle Client e pasta de saida.

Exemplo de campos importantes:

ORACLE_USER=usuario
ORACLE_PASSWORD=senha
ORACLE_DSN=DBRAWZN
ORACLE_CLIENT_DIR=C:\app\client\anderson.dossantos\product\19.0.0\client_1\bin
TNS_ADMIN=C:\app\client\anderson.dossantos\product\19.0.0\client_1\network\admin
TABLE_NAME=USR_ATENDIMENTO_5ESTRELAS.RAW_LND_5_ESTRELAS_DETALHADO
OUTPUT_FILE_NAME=5_ESTRELAS_EXTRACAO
OUTPUT_DIR=data\oracle
LOG_FILE_NAME=log_extracao_oracle.xlsx

Ponto importante:
scripts/.env.oracle nao deve ser enviado para GitHub e nao deve ser compartilhado
com senha real. Ele e um arquivo local da maquina.


6. COMO FUNCIONA A EXTRACAO ORACLE

Script:

scripts/extracao_oracle_exemplo.py

Comando:

python scripts/extracao_oracle_exemplo.py

O que o script faz:

1. Le o arquivo scripts/.env.oracle.
2. Inicializa o Oracle Client.
3. Conecta no banco usando ORACLE_DSN ou HOST/PORT/SERVICE.
4. Monta um SELECT * FROM TABLE_NAME.
5. Aplica SQL_WHERE, se estiver configurado.
6. Gera um CSV separado por ponto e virgula.
7. Gera um log Excel com data, duracao, tabela, filtro e quantidade de linhas.

Filtro opcional:

SQL_WHERE deve ser escrito sem a palavra WHERE.

Exemplo:

SQL_WHERE=ANO = 2026 AND MES = 6

Saidas da extracao:

data\oracle\5_ESTRELAS_EXTRACAO.csv
data\oracle\log_extracao_oracle.xlsx

Observacao:
O nome exato depende de OUTPUT_DIR, OUTPUT_FILE_NAME e LOG_FILE_NAME no
scripts/.env.oracle.

10. O QUE A PRE-VALIDACAO DE AVALIACOES FAZ

Entrada:

data/junho_incompleto_5_estrelas.csv
ou caminho configurado em PIPELINE_AVALIACOES_ENTRADA

Saida final:

data_exec_indiv/avaliacoes/pipeline_pre_validacao_avaliacoes_base_final.csv

Resumo mestre:

saida_resumo_avaliacoes/pipeline_pre_validacao/pipeline_pre_validacao_resumo_mestre.json

Etapas:

00 - verificacao de campos
Verifica campos importantes e gera auditorias de valores invalidos.

01 - limpeza
Padroniza colunas, remove linhas sem nota valida e prepara a base.

02 - contratacao
Preenche CONTRATACAO e, quando possivel, UF usando o insumo.

03 - nota
Calcula NOTA GERAL.

04 - classificacao
Aplica regra_classificacao.xlsx.

05 - local editado
Preenche LOCAL EDITADO usando insumos.

06 - ajustes finais
Aplica regra_ajuste_final.xlsx.

07 - operadora
Preenche OPERADORA usando regras_operadora.xlsx.

08 - meta
Preenche META.

09 - resultado da unidade
Calcula RESULTADO DA UNIDADE.

10 - status unidade
Define STATUS UNIDADE.

11 - analise de dados
Gera Excel e TXT de analise.

15. PROBLEMAS COMUNS E COMO EXPLICAR

Problema: a extracao Oracle nao conecta.

Verificar:
- usuario e senha no scripts/.env.oracle;
- ORACLE_DSN;
- TNS_ADMIN;
- tnsnames.ora;
- Oracle Client instalado.

Problema: a pipeline nao encontra o CSV.

Verificar:
- se o arquivo existe no caminho configurado;
- se PIPELINE_AVALIACOES_ENTRADA ou PIPELINE_NEGATIVAS_ENTRADA esta correto;
- se o nome do arquivo foi alterado.

Problema: a base final saiu com zero linhas.

Verificar:
- resumo da etapa 01;
- se NOTA1 a NOTA5 vieram sem valores numericos validos;
- se a limpeza removeu linhas sem nota valida.

Problema: tem muitos locais sem contratacao ou sem UF.

Verificar:
- auditorias da etapa 02;
- aba contratacao do insumos 5 estrelas.xlsx.

Problema: tem linhas sem classificacao.

Verificar:
- auditoria da etapa 04;
- regra_classificacao.xlsx.

Problema: tem linhas sem operadora.

Verificar:
- auditoria da etapa 07;
- regras_operadora.xlsx.

Problema: Excel nao sobrescreve.

Verificar:
- se o arquivo esta aberto no Excel;
- fechar o arquivo e rodar novamente.


16. ORDEM RECOMENDADA PARA OPERACAO MENSAL

1. Atualizar ou extrair a base Oracle.
2. Colocar o CSV de avaliacoes no caminho correto.
3. Colocar o CSV de negativas no caminho correto, se houver.
4. Rodar:

python execucoes_pipeline/exec_pre_validacao.py

5. Abrir as auditorias principais.
6. Ajustar insumos e regras, se necessario.
7. Rodar novamente a pre-validacao.
8. Quando estiver validado, rodar:

python execucoes_pipeline/exec_gerar_arquivos_bi.py

9. Se precisar dos arquivos por grupo/classificacao, rodar:

python execucoes_pipeline/exec_separacao.py

10. Conferir os arquivos finais e entregar para o destino correto.


17. RESUMO PARA ENCERRAR A APRESENTACAO

Para a pessoa assumir o projeto, ela precisa dominar estes pontos:

1. Configurar Python, bibliotecas e Oracle Client.
2. Preencher scripts/.env.oracle sem versionar senha.
3. Entender onde entra o CSV de avaliacoes e negativas.
4. Saber que as regras de negocio ficam principalmente em utils/insumos.
5. Rodar os comandos principais em execucoes_pipeline.
6. Conferir as auditorias antes de gerar o BI final.
7. Saber onde ficam os arquivos finais e os resumos.

Com isso, a pessoa consegue operar o processo, investigar divergencias e ajustar
os insumos sem precisar alterar codigo na maior parte dos casos.
